# Contributing

## Development workflow

1. Validate structure and syntax:
   - `make validate`
   - `make lint`
2. Build locally:
   - `make build`
3. Keep changes focused and include updates to relevant docs/examples.

## Pull requests

- Keep PRs small and reviewable.
- Describe Zephyr, XS, or TI SDK assumptions in PR descriptions.
- Include the exact commands used for verification.
